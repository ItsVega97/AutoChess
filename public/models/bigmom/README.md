# 🍰 Piratas de Big Mom

Modelos 3D de esta tripulación. Deja aquí un archivo por personaje, con
**exactamente** el nombre de la tabla (el nombre es el `id` interno, no el
nombre visible):

| Archivo | Personaje | Coste |
|---|---|---|
| `perospero.glb` | Perospero | 1 🪙 |
| `cracker.glb` | Cracker | 2 🪙 |
| `smoothie.glb` | Smoothie | 3 🪙 |
| `katakuri.glb` | Katakuri | 4 🪙 |
| `bigmom.glb` | 👑 Big Mom | 5 🪙 |

Formato: **`.glb`** (glTF binario). Si tu modelo es `.gltf` + carpeta de
texturas, conviértelo a `.glb` para que sea un único archivo.

Recomendaciones: pocos polígonos (unos pocos miles de triángulos), pose neutra
o T-pose, y que el modelo mire hacia el **+Z** con los pies en el origen — el
juego lo escala y lo orienta solo, pero partir de ahí da mejor resultado.

Un personaje sin modelo aquí sigue usando su ficha con el retrato, así que
puedes ir subiéndolos poco a poco.
